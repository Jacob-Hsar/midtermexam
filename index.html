Web Authoring

01 Introduction to HTML & HTML Basics L1 · L2 ▼

HTML (Hypertext Markup Language) is the standard markup language used to create and structure the content of web pages. HTML is not a programming language; it describes the structure and meaning of content by using elements and tags.

What does HTML do?

HTML tells a web browser what each part of a page represents. For example, a heading is marked as a heading, normal text is placed in a paragraph, an image is inserted with an image element, and a hyperlink is created with an anchor element. The browser reads the HTML document and renders the page for the user.

<html> root element <head> page information <title> browser-tab title <body> visible content

Important HTML elements

<h1>–<h6> headings <p> paragraph <br> line break <ul> unordered list <ol> ordered list <li> list item <a href> hyperlink <img src> image

Basic document structure

<!DOCTYPE html>
<html>
  <head>
    <title>My Web Page</title>
  </head>
  <body>
    <h1>Welcome</h1>
    <p>This is my first web page.</p>
  </body>
</html>

How to remember the structure: <html> contains the whole document. <head> contains information about the document that is generally not displayed as page content. <body> contains the content users see on the page.

TagA markup name such as <p> or <h1>.
ElementA complete HTML component, usually including an opening tag, content, and closing tag.
AttributeExtra information inside an opening tag, such as href or src.
Exam Focus
  • Know the full meaning of HTML: Hypertext Markup Language.
  • Know the purpose of <head> and <body>.
  • Remember <br> creates a line break.
  • Remember <a> creates a hyperlink and href identifies its destination.
  • Remember <img> displays an image and src identifies the image source.
02 WYSIWYG Software L5 ▼

WYSIWYG means What You See Is What You Get. WYSIWYG web-authoring software allows a user to create or edit a web page visually rather than writing every line of HTML manually.

How WYSIWYG software works

The user works with a visual editor that resembles the final web page. They can add text, images, buttons, tables, links, and other objects through menus, panels, or drag-and-drop tools. The software generates or edits the underlying HTML and related files.

Examples from the notes: Adobe Dreamweaver and Mobirise.

✓ Advantages
  • Faster workflow: common page elements can be created quickly.
  • Beginner friendly: users can design visually without knowing every HTML tag.
  • Instant visual preview: the designer can see approximately how the page will look.
  • Useful for templates: repeated page layouts can be created more efficiently.
✗ Disadvantages
  • Messy generated code: automatic code may contain unnecessary elements or formatting.
  • Less fine-grained control: advanced users may need direct HTML/CSS editing.
  • Possible cost: some professional tools require a paid licence.
  • Learning is still important: understanding HTML helps users troubleshoot generated pages.

When should you use WYSIWYG software?

It is especially useful when a learner needs to build a website quickly, when visual design is important, or when the user is still developing coding skills. For complex websites, understanding the generated HTML is still valuable because visual tools do not remove the need for good structure, testing, accessibility, and maintenance.

Visual editingWork with page elements through a graphical interface.
Code generationThe software creates or modifies the underlying web code.
PreviewCheck the visual appearance before publishing the site.
Exam Focus
  • WYSIWYG = What You See Is What You Get.
  • The main idea is visual web-page creation without manually writing all the code.
  • A key advantage is that it is faster and easier for beginners.
  • A key disadvantage is that generated code can be messy or less controllable.
03 Multimedia Web Content L6 ▼

Multimedia web content includes media such as images, audio, video, maps, and other interactive or externally hosted content. Multimedia can make a website more informative and engaging when it is relevant to the purpose of the page.

Embedded content

Embedded content is content supplied by another service or website and displayed inside your own web page. A common method is the <iframe> element.

<iframe
  src="https://example.com/video"
  title="Example embedded content">
</iframe>

The page does not necessarily store a complete copy of the external content. Instead, the browser loads the embedded resource according to the source and its permissions.

✓ Advantages
  • No need to host every external media file yourself.
  • Can save server storage for externally hosted content.
  • Can add useful videos, maps, or other resources quickly.
  • Can improve the learning experience when media supports the topic.
✗ Disadvantages
  • If the source removes or changes the content, your page may also be affected.
  • Heavy embedded content can increase loading time.
  • The external service may require an internet connection.
  • Permissions, copyright, privacy, and source policies must be considered.

Good practice when using multimedia

  • Use media that directly supports the purpose of the page.
  • Use appropriate titles or labels so users understand the content.
  • Compress large images and media where appropriate to improve performance.
  • Check that external content is still available.
  • Respect copyright and obtain permission where required.
  • Test the page on different screen sizes and browsers.
Exam Focus
  • Know that <iframe> can be used to embed external content.
  • Remember the two key disadvantages in this syllabus: source removal/change and slower loading.
  • Be able to explain why embedded content can reduce the amount of media that must be hosted directly.

Input · Process · Output

04 Computer Components & I/O System L1 · L2 ▼

A computer system can be understood through the Input → Process → Output model. Input devices provide data to the computer, the processor works on that data, and output devices present the resulting information to the user.

InputData or instructions entered into a computer, for example through a keyboard, mouse, microphone, scanner, or touchscreen.
ProcessThe CPU processes instructions and data to perform calculations and make decisions.
OutputInformation produced by the system, such as text on a monitor, printed documents, sound, or a projected image.
Input Devices
Keyboard, mouse, microphone, scanner, touchscreen.
Output Devices
Monitor, printer, speaker, projector.
CPU
Central Processing Unit; it executes instructions and processes data.
Motherboard
The main circuit board that provides connections between major computer components.
RAM
Volatile working memory used for data and programs currently in use.
ROM
Non-volatile memory associated with essential startup instructions or firmware.

Example of the Input–Process–Output cycle

Suppose a student enters 10 + 5 using a keyboard. The keyboard provides the input. The CPU processes the arithmetic operation. The monitor then displays the output 15.

RAM vs ROM

RAMVolatile; temporary working storage; contents are lost when power is removed.
ROMNon-volatile; retains information when power is removed; used for essential startup/firmware information.
Exam Focus
  • Keyboard and mouse are examples of input devices.
  • Monitor and printer are examples of output devices.
  • CPU = Central Processing Unit.
  • RAM is volatile; ROM is non-volatile.
  • The motherboard connects major components of the computer.
05 RISC & CISC Processors L5 ▼

RISC and CISC describe different approaches to processor instruction sets.

RISCReduced Instruction Set Computer. Uses a relatively small set of simple instructions. The approach aims to make instructions straightforward and efficient to execute.
CISCComplex Instruction Set Computer. Uses a larger set of more complex instructions, with some instructions capable of performing more work.

RISC characteristics

  • Uses a smaller collection of simple instructions.
  • Instructions are designed to be efficient and relatively straightforward.
  • The approach is associated with efficient processing and lower power use in many modern devices.
  • The syllabus associates RISC with modern devices such as smartphones and tablets.

CISC characteristics

  • Provides a larger collection of more complex instructions.
  • A single instruction may perform a more complicated operation.
  • The syllabus associates CISC with older personal-computer designs and higher power requirements.

Easy memory trick: RISC = Reduced + Simple; CISC = Complex + Large.

Exam Focus
  • RISC stands for Reduced Instruction Set Computer.
  • CISC stands for Complex Instruction Set Computer.
  • RISC is associated with a smaller set of simple instructions.
  • CISC is associated with a larger set of complex instructions.
  • Be prepared to compare them in terms of instruction complexity, efficiency, and typical use.
06 BIOS and ROM L6 ▼

BIOS (Basic Input/Output System) is firmware that helps a computer start. When the computer is switched on, firmware performs important startup tasks before the operating system is fully loaded.

What happens during startup?

  1. The computer is powered on.
  2. The firmware begins running.
  3. Hardware is checked during the startup process, commonly referred to as POST (Power-On Self-Test).
  4. The firmware identifies the resources needed for startup.
  5. The boot process continues and the operating system is loaded.

UEFI (Unified Extensible Firmware Interface) is the modern firmware interface that has largely replaced traditional BIOS implementations. In the syllabus context, UEFI is associated with support for larger drives and faster booting.

Why firmware matters

The operating system cannot simply appear by itself when the computer is powered on. The system needs low-level startup instructions to initialise hardware and begin the boot process. Firmware provides this early-stage functionality.

BIOSTraditional firmware interface used during startup to initialise hardware and begin loading the operating system.
UEFIModern firmware interface with additional capabilities, including support for larger drives and modern boot features.
Exam Focus
  • BIOS = Basic Input/Output System.
  • BIOS/firmware is used to start the computer, check hardware, and begin loading the operating system.
  • POST is the hardware-checking stage during startup.
  • UEFI is the modern replacement for traditional BIOS implementations.

Computing for All

07 Network Types & Topologies L1 · L2 ▼

A computer network is a collection of connected devices that can communicate and share resources. Networks can be classified by their geographical coverage and by their physical or logical layout, called a topology.

Network Types

LAN
Local Area Network. Covers a relatively small area such as a home, classroom, office, or single building.
WAN
Wide Area Network. Covers a large geographical area and can connect networks across cities, countries, or continents. The Internet is a major example of a WAN.
PAN
Personal Area Network. A small network centred around one person, commonly using short-range technologies such as Bluetooth.

Network Topologies / Layouts

Point-to-point One direct connection between two devices. Example: a direct computer-to-printer connection.
Bus Devices share a single main backbone cable. Advantage: simple and relatively inexpensive. Disadvantage: backbone failure can affect the whole network.
Ring Devices form a closed loop. In the syllabus model, data travels around the ring in one direction. Potential issue: data may need to pass through several devices.
Star Each device connects to a central hub or switch. Common in homes and offices; one device failing normally does not disconnect the other devices.
Mesh Devices have multiple direct connections, with the full mesh connecting each device to every other device. Very reliable because alternative paths can exist, but it is expensive and complex.

Why topology matters

The topology affects how devices communicate, how easy a network is to maintain, what happens when a connection fails, and how much equipment or cabling is required. A suitable topology depends on the size, cost, reliability requirements, and purpose of the network.

StarCentral device; easy to manage; common in modern homes and offices; central-device failure can affect the network.
MeshMultiple paths; highly reliable and redundant; more expensive and complicated to install.
BusShared backbone; inexpensive and simple, but backbone problems can affect many devices.
RingClosed loop; data follows the ring; communication can depend on the path through other devices.

PAN example

A smartphone connected to Bluetooth headphones is a simple example of a PAN. The devices are close to one person and communicate over a short range.

Exam Focus
  • LAN = Local Area Network.
  • WAN = Wide Area Network.
  • PAN = Personal Area Network.
  • Star uses a central hub/switch.
  • Mesh provides high redundancy and reliability through multiple connections.
  • Bus uses a single backbone cable.
  • Ring forms a closed loop.
  • Point-to-point is a direct connection between two devices.

Read the definition first, then study the explanation and example. Finally, close the lesson and try to explain the topic from memory. Pay special attention to the Exam Focus box because the same concepts appear in the examination questions.

Section 6 · Long Questions (10 marks each)

61. (Sample Answer) To create a multiple-page website for a charity, I would first plan the site structure and folder hierarchy. Using WYSIWYG software like Adobe Dreamweaver or Mobirise, I can drag and drop elements to create a template page. I would design a consistent banner, navigation menu, and footer, then duplicate this template to create additional pages. For multimedia, I would embed a YouTube video of the charity's work using an <iframe> tag, ensuring it is relevant to the target audience. I would add audio clips of interviews, but ensure I have permission to use them. I would compress images to keep the site fast and test the site on different devices to ensure responsiveness.

62. (Sample Answer)
Point-to-point: Direct connection between two devices. Scenario: connecting a laptop to a printer via USB.
Bus: All devices connect to a single backbone cable. Scenario: older, small office networks. Cheaper, but if the main cable breaks the whole network goes down.
Ring: Devices connected in a closed loop; data travels in one direction. Scenario: some older office buildings. Can be slow as data passes through each device.
Star: All devices connect to a central hub/switch. Scenario: modern homes and offices. Easy to troubleshoot, but if the hub fails the network fails.
Mesh: Every device connects to every other device. Scenario: military or large corporate networks where reliability is critical. Very robust but expensive and complex to set up.
